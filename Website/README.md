# LearnConnect - E-Learning Platform

An enterprise-grade ASP.NET Core MVC e-learning platform connecting learners with content creators. Features multi-role authentication (Learners, Content Creators, Admins), digital content management, shopping cart system, promotions, and analytics.

## Quick Start

### Prerequisites
- .NET 8 SDK or later
- SQL Server (LocalDB or full installation)
- Visual Studio 2022 / VS Code / JetBrains Rider
